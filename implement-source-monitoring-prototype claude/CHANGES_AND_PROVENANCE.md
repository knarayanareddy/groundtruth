## Baseline used

The environment's project was an empty React 19 / Vite 7 / Tailwind 4 / TypeScript scaffold, **not** a checkout of `starting_point/`. I compared them: `tsconfig.json`, `src/main.tsx`, `src/utils/cn.ts` and `src/index.css` are byte-identical to the starting point; `package.json` has the same pinned versions of every shared dependency except the starting point's `lucide-react ^1.72.0` (absent here and not needed); the scaffold's `vite.config.ts` equals the starting point's minus its `server: { host: "0.0.0.0", allowedHosts: true }` block. So "on top of the supplied source" means: the same toolchain and reused unchanged files, with the legacy product code replaced. I did not copy the legacy views into the working tree.
